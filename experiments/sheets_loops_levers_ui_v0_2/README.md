# Sheets, Loops, and Levers UI v0.2

A coordinated thematic essay for three distinct organizations of mechanistic-interpretability information:

- **Sheets:** étale charts over ordered depth;
- **Loops:** holonomy of associations over a genuine closed time/context phase;
- **Levers:** registered-action reachability in the tangent fiber;
- **Synthesis:** one selected mechanism carried through all three views.

## Run

```powershell
python build_fixture.py
python -m http.server 8766
```

Open `http://localhost:8766/`.

The same motif selection persists across all four chapters. Use the chapter tabs or `1`–`4`; arrow keys move between chapters. **Agent view** exports a bound JSON snapshot containing the selected state, evidence class, claim boundary, and next evidence action.

## Evidence boundary

The fixture is globally normalized and deterministic. The geometry and derived matrices are internally coherent, but they are not model activations. The reachability primitive has an accepted 256-pair synthetic confirmation in `../reachability_information_gain_v0_1/`; neural-model control and human usability remain untested.

## Contracts

```powershell
python -m unittest discover tests
node --test tests/*.test.mjs
```

`visual_test_receipt.json` records responsive and interaction checks at 1024, 736, and 360 CSS pixels. The page is dependency-free and can also be opened directly after running `build_fixture.py`.

## What each chapter answers

- **Sheets:** Where does a target become locally indistinguishable over ordered depth?
- **Loops:** What association frame returns changed after an actual closed context traversal?
- **Levers:** Which local directions can a registered intervention set reach?
- **Synthesis:** Does depth convergence predict transported control compatibility on held-out inputs?

The final synthesis is deliberately a candidate claim. A real experiment must bind all three views to the same activation subspace, samples, and intervention registry.
